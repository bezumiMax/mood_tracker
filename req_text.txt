Требования к пояснительной записке к курсовому проекту по дисциплине «Разработка клиент-серверных приложений»Пояснительная записка должна включать в себя следующую информацию:
Наименование
Объем, стр.
Комментарий
Титульный лист
Содержание
Общая информация о проекте из описания для модерации (название, краткое описание смартаппа, запуск и т.д.)
Постановка и анализ задачи
Описание приложения с точки зрения пользователя (используя Описание смартаппа, Категории, Примеры запуска, Превью, Инструкция для тестирования). Целевая аудитория приложения.
Описание проектных решений
Схема и описание архитектуры проекта: основные компоненты (фронтенд, бэкенд и приложение СмартКод) с кратким описанием.Описание взаимодействия компонент (список методов API с кратким описанием).
Перечень и краткое описание использованных технологий, инструментов, сторонних модулей и компонент. Используемые облачные сервисы (такие как  Github, Heroku и т. д.) с кратким описанием применения в проекте.Описание структуры базы данных.Ссылки на репозитории.Ссылки на REST API бэкенда и веб-интерфейс фронтенда.
Заключение
Описание полученных результатов: что получилось реализовать, варианты дальнейшего развития, варианты монетизации.
